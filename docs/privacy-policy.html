Draw.io AI Sidebar 隐私政策

最后更新：2026-04-15

本隐私政策适用于 Chrome 扩展 Draw.io AI Sidebar（以下简称“本扩展”）。

1. 适用范围

本扩展用于在 app.diagrams.net 页面中提供 AI 辅助绘图功能，包括根据用户文本或图片上下文生成 draw.io XML 并可注入到画布。

2. 我们处理的数据类型

  1. 用户输入内容：你在侧边栏输入的文本提示词和多轮对话历史。
  2. 图表相关内容：当前画布 XML 和模型返回 XML。
  3. 图片内容：你上传的图片、截图与标注内容。
  4. 本地配置数据：baseLLMUrl、API Key、模型列表、Profile 名称、温度、max_tokens，以及历史记录。
  5. 诊断字段：模型返回的 token 用量字段。

3. 数据如何被使用

  1. 调用你配置的模型接口以生成图表 XML。
  2. 在本地展示并维护多轮对话与版本切换。
  3. 在 app.diagrams.net 页面读取/注入 XML 完成编辑流程。
  4. 支持截图标注后作为模型输入上下文。

4. 数据共享与第三方

  1. 本扩展会将必要输入发送到你在设置中填写的第三方模型接口地址。
  2. 本扩展默认不会将上述数据发送到开发者自建服务器（除非你将模型地址配置为该服务器）。
  3. 本扩展运行在 app.diagrams.net 页面环境中，并与该页面进行功能交互。

5. 数据存储位置与保留期限

  1. 配置、对话历史、XML 版本主要保存在浏览器本地存储。
  2. 上传图片与截图标注主要用于当前会话，通常不会在扩展内长期持久化。
  3. 你可手动清空历史，或卸载扩展以移除本地数据。

6. 权限与用途说明

  1. storage：保存本地配置、对话历史、XML 版本记录。
  2. tabs / activeTab：在当前标签页触发侧边栏与截图流程。
  3. scripting：执行读取当前 XML、注入 XML 等脚本。
  4. host_permissions（https://app.diagrams.net/*）：仅在该站点运行内容脚本并完成交互。

7. 不售卖个人数据

我们不会出售你的个人数据。

8. 儿童隐私

本扩展不面向未满 13 周岁儿童提供定向服务。若你认为存在儿童信息被误处理，请通过下方联系方式联系我们。

9. 安全措施

我们采取合理措施保护数据安全。API Key 等配置保存于浏览器本地；通过网络发送到第三方模型服务的数据受对应服务商安全机制约束。

10. 你的权利与控制

  1. 修改或删除扩展内配置。
  2. 清空对话历史。
  3. 卸载扩展并删除本地数据。
  4. 停止使用第三方模型服务或更换服务商地址。

11. 政策更新

若本隐私政策有重要变更，我们将通过扩展版本更新本页面内容。
