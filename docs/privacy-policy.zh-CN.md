# Draw.io AI Sidebar 隐私政策

最后更新：2026-04-15

本隐私政策适用于 Chrome 扩展 Draw.io AI Sidebar（以下简称“本扩展”）。

## 1. 适用范围

本扩展用于在 app.diagrams.net 页面中提供 AI 辅助绘图功能，包括根据用户文本或图片上下文生成 draw.io XML 并可注入到画布。

## 2. 我们处理的数据类型

本扩展可能处理以下数据：

1. 用户输入内容

- 你在侧边栏输入的文本提示词。
- 你在多轮对话中的历史消息。

2. 图表相关内容

- 当前画布的图表 XML（用于“基于当前图修改”）。
- 模型返回的图表 XML。

3. 图片内容

- 你上传的图片。
- 你通过“截图并标注”生成的截图与标注内容。

4. 本地配置数据

- 你在扩展设置中填写的参数，如 baseLLMUrl、API Key、模型列表、Profile 名称、温度、max_tokens。
- 对话历史与 XML 版本历史。

5. 诊断与统计字段

- 模型接口返回的 token 用量字段（如 total_tokens）。

## 3. 数据如何被使用

上述数据仅用于以下目的：

1. 调用你配置的 AI 模型接口以生成图表 XML。
2. 在本地展示、维护多轮对话与版本切换能力。
3. 在 app.diagrams.net 页面读取/注入 XML 以完成编辑流程。
4. 支持截图标注后作为模型输入上下文。

## 4. 数据共享与第三方

1. 本扩展会将必要输入发送到你在设置中填写的第三方模型接口地址（baseLLMUrl 对应服务）。
2. 本扩展默认不会将上述数据发送到开发者自建服务器（除非你将 baseLLMUrl 配置为相关地址）。
3. 本扩展运行在 app.diagrams.net 页面环境中，并与该页面进行功能交互。

请同时查阅你所使用的第三方模型服务商与 app.diagrams.net 的隐私条款。

## 5. 数据存储位置与保留期限

1. 配置、历史对话、XML 版本主要保存在浏览器本地存储（chrome.storage.local）。
2. 上传图片与截图标注主要用于当前会话流程，通常不会在扩展内长期持久化。
3. 你可在扩展内手动清空历史，或卸载扩展以移除本地存储数据。

## 6. 权限与用途说明

本扩展申请的权限及用途：

1. storage：保存你的本地配置、对话历史、XML 版本记录。
2. tabs / activeTab：在当前标签页中触发侧边栏与截图流程。
3. scripting：在目标页面执行读取当前 XML、注入 XML 等脚本。
4. host_permissions（https://app.diagrams.net/*）：仅在该站点运行内容脚本并完成绘图交互。

## 7. 不售卖个人数据

我们不会出售你的个人数据。

## 8. 儿童隐私

本扩展不面向未满 13 周岁儿童提供定向服务。若你认为存在儿童信息被误处理，请通过下方联系方式联系我们。

## 9. 安全措施

我们采取合理措施保护数据安全。但你需要理解：

1. API Key 等配置保存于浏览器本地环境。
2. 通过网络发送到第三方模型服务的数据受对应服务商安全机制约束。

## 10. 你的权利与控制

你可以：

1. 随时修改或删除扩展内配置。
2. 清空对话历史。
3. 卸载扩展并删除本地数据。
4. 停止使用第三方模型服务或更换服务商地址。

## 11. 政策更新

若本隐私政策有重要变更，我们将通过扩展发布版本更新本页面内容。
